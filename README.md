# СКОЛ — лендинг строительной команды

Одностраничный сайт на React, TypeScript и Vite. Интерфейс на русском языке, визуальная система — liquid glass / bento с графитовым фоном и лавандовой рамкой.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Структура

- `src/App.tsx` — интерфейс, навигация, фильтры и состояние модального окна.
- `src/styles.css` — токены дизайна, раскладка, темы и адаптивные состояния.
- `index.html` — русская локаль, метаданные и подключение шрифта.

## Состояние интеграций

Форма заявки пока демонстрационная и не передаёт данные в CRM, почту или мессенджер. Для запуска лидогенерации нужно подключить согласованный канал отправки. Фотография в Hero также пока заменена CSS-иллюстрацией-заглушкой.
